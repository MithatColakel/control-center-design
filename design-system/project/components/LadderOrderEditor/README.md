# LadderOrderEditor

The connection order editor, in a right sheet (480 px) on Country 360 › Connection order, next to its evidence (walk, changes). No separate "Country Restrictions" page.

Rung row: handle · position · long rung label ("AmneziaWG 3.1 · UDP") + one sub line · evidence (first-rung success in this country, 7 d, with margin of error and n, meter) · on / off switch.
- AmneziaWG 3.1 · UDP is always on (lock icon, disabled switch).
- Moved rungs get a 3 px blue edge and "Moved up from 3". Drop place: dashed `ring` line. Keyboard: Alt + ↑ / ↓.
- Rungs the brand's app cannot walk: amber "Not in this brand's app" (from `WALKABLE_RUNGS`).
- 50 s limit line between rungs that fit and rungs that may never be tried.
- Off rungs: dashed, struck label, "Off · never tried here".
- Footer: Reset to default · Cancel · **Review changes** (opens the review confirm step). Nothing is saved before the review.
Words: Ladder plan §4 (rung, order, connect, first rung, too little data, period). Retired words are not used.
