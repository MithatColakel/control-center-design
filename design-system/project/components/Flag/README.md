# Flag

Country = flag + name. ISO code only in the tooltip ("IR · Iran").
Sizes: 16 × 12 inline / chips, 20 × 15 rows, 24 × 18 cards, 40 × 30 Country 360 title. 1 px `flag-ring` so white flags show on white.
Names: `Intl.DisplayNames` in EN or TR.

**Proposal:** SVG flags from `flag-icons` (MIT, ~1 kB per flag, load on demand) instead of emoji flags. Emoji flags do not render on Windows, where they show two letters. If not approved, keep emoji and the design stays the same size.
