# Colors

See `tokens.json` › color. shadcn names first (`background`, `card`, `primary` …), then panel roles, status, charts. Two themes: light and dark; the panel has light / dark / system.
Neutral default: primary is near-black / near-white. The brand layer may replace `primary`, `primary-hover`, `primary-foreground`, `ring` and `sidebar-accent` (private page); nothing else. `handoff/index.css` has the shadcn HSL values for `src/index.css`.
