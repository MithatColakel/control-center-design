# Overlays

- Row menu: shadcn `DropdownMenu`. First item opens the object. Items that need a confirm step end with "…". Destructive items last, red, after a separator.
- Tooltip: shadcn `Tooltip`, inverted (`tooltip-bg`). Use for definitions (source labels, Ladder terms), ISO codes, exact times. Never the only place for needed information.
- Toast: Sonner, bottom right, 5 s, one line title + one line detail; success has "Undo" where possible, error has "Retry" and an error id.
