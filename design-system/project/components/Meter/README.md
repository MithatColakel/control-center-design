# Meter

Thin bar for a value against a target or a limit (6 px; tall 8 px).
- Rate vs target: scale 90–100 %, tick at 99 % (`foreground` 55 %). Fill colour = status of the value.
- Load vs limit: users now / limit per server. **Open (P1.2):** there is no capacity number today. Without a limit the bar is neutral and hatched with "no limit set".
