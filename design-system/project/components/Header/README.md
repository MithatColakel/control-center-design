# Header

Top bar, 56 px, sticky, `header-bg` with blur.

- Left: sidebar toggle, crumb. **The crumb always ends with the page name in bold** (VPN-704: the header never named the page). On 360 pages: group › list › object ("Fleet › Servers › frankfurt-2").
- Right: "N open alerts" (red, opens the Overview alert inbox; replaces the bell and the sidebar badge), language EN / TR, theme (light / dark / system), account menu ("OP": theme, language, log out).
- No alerts: neutral button "No open alerts".
- Mobile: menu button, group over page title, alert icon with count, account.
