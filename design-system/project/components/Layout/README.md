# Layout

Breakpoints: sm 640, md 768, lg 1024, xl 1280, 2xl 1440. Frames: 1440, 1024, 375. Grid: 12 / 8 / 4 columns, gap 16. See the card for the rules against sideways scroll.

At 375 (below 768 px), as in the approved Mobile 375 frames (IA.md §12):
- Controls 44 px: every tap target is at least 44 px high (buttons, icon buttons 44 × 44, tabs, segmented controls, filter buttons, inputs, menu items, header buttons, list rows).
- No page-level sideways scroll; only the tab row scrolls inside itself.
- Menu: drawer 300 px over a scrim. Language and theme are in the drawer foot.
- Dialogs and confirm steps 343 px (16 px from each edge), footer buttons share the width. Forms with more than one field: full-width bottom sheet.
- Tables: NarrowTable stacked rows, "N of M rows" + "Load more".
