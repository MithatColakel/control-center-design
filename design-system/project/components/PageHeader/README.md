# PageHeader

Title and the question the page answers (IA rule: one page = one question).

- List page: h1 + question (14 muted) + actions right (time range, outline actions, one primary).
- 360 page: object identity first (flag 40 × 30 or status chip), h1, key chips (status, order), question, one meta line (sources with sample sizes, freshness), actions.
- 375: title and question stack; actions go to one row under them; extra actions in "⋯".
